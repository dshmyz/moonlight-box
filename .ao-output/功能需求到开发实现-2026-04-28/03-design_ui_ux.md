## 1. User Journeys & Interaction Flows（用户旅程与交互流程）

### 1.1 首次使用流程

```
访问 URL (http://localhost:8080)
  → 路由守卫检测未登录
    → 重定向到 /login
      → 输入 username/password
        → 登录成功 → JWT Token 存储到 localStorage
          → 获取用户信息和角色
            → 根据角色显示对应菜单
              → 重定向到 /dashboard
```

### 1.2 核心任务流程

**发布包**：
```
npm publish → 后端 API → (不需要前端操作)
管理后台查看 → 包列表页 → 筛选 "我的包" → 查看版本列表
```

**搜索包**：
```
管理后台 → 包列表页
  → 输入搜索关键词
    → 实时搜索（debounce 300ms）
      → 结果列表显示匹配包
        → 点击包名 → 展开详情（版本、下载量、元数据）
```

**管理用户**：
```
管理后台 → 用户管理
  → 点击 "创建用户" → 弹出对话框
    → 填写 username, password, email, 角色
      → 提交 → 后端创建成功
        → 刷新列表 → 新用户出现
  → 编辑角色 → 下拉选择 → 保存
```

### 3.3 通用状态处理

| State | Component | Behavior |
|-------|-----------|----------|

## 5. Accessibility Standards（无障碍标准）

| Standard | Implementation |
|----------|---------------|
| 色彩对比度 | 符合 WCAG AA (文字 4.5:1) |
| 键盘导航 | Tab 顺序合理，Enter/Space 触发动作 |
| 焦点指示 | Element Plus 默认焦点环 |
| 屏幕阅读器 | `<el-form>` 的 `label` 属性、ARIA 标签 |
| 错误提示 | 表单错误通过 `aria-describedby` 关联 |
