# 软件包中心重新设计规格说明

**日期：** 2026-05-05
**状态：** 已批准

## 1. 概述

重新设计软件包中心（BrowsePage）界面，采用极简网格流设计，实现简洁清爽的视觉风格。

## 2. 设计目标

- **简洁清爽**：减少视觉层级，弱化装饰元素
- **轻量筛选**：搜索和筛选更加轻量化
- **足够留白**：页面呼吸感更强
- **响应式布局**：适配不同屏幕尺寸

## 4. 响应式断点

| 断点 | 列数 | 布局模式 |
|------|------|----------|
| ≥1200px | 3列 | 网格卡片 |
| ≥768px | 2列 | 网格卡片 |
| <768px | 1列 | 紧凑单列列表（无卡片背景） |

## 5. 组件样式规格

### 5.1 Hero 区域
- 无背景色、无边框
- 标题：24px，font-weight: 600，#1f2937
- 副标题：14px，#6b7280
- 圆角：8px

### 5.2 搜索栏
- 宽度：100%（自适应）
- 高度：40px
- 边框：1px solid #e5e7eb
- 圆角：8px
- 背景：#fafafa（默认）/ #fff（聚焦）
- 聚焦：蓝色边框 + 光晕
- 按钮：蓝色背景 #2563eb，hover 变深

### 5.3 筛选栏
- 无背景色、无边框
- 类型按钮组：圆角 6px，选中蓝色背景
- 排序下拉：同输入框样式
- 包数量：普通文字色，13px

### 5.4 网格卡片
- 无边框
- 圆角：8px
- 内边距：20px
- hover：背景变为 #fafbfc
- 字体：
  - 包名：15px, font-weight: 500, #1f2937
  - 描述：13px, #6b7280
  - 版本/下载：12px, #9ca3af
  - 标签：11px, 圆角 4px

### 5.5 紧凑列表（小屏）
- 无卡片背景
- 每行 padding: 12px 0
- 底部分隔线：1px solid #f3f4f6
- hover：背景 #fafbfc
