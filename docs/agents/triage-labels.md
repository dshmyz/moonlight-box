# Triage Labels

The canonical triage roles and their label strings for this repo.

## Category roles

| Role | Label |
|------|-------|
| bug | `bug` |
| enhancement | `enhancement` |

## State roles

| Role | Label |
|------|-------|
| needs-triage | `needs-triage` |
| needs-info | `needs-info` |
| ready-for-agent | `ready-for-agent` |
| ready-for-human | `ready-for-human` |
| wontfix | `wontfix` |

## Notes

- Every triaged issue should carry exactly one category role and one state role.
- These are the default label names. If the repo's GitHub labels differ, update this file to match.
- The `triage` skill reads this file to know which labels to apply.
